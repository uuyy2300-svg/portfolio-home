个人网站三屏合并版

打开方式：
1. 解压整个 portfolio_home_3screens 文件夹。
2. 直接双击 index.html 即可预览。
3. 如果浏览器对本地 iframe 有限制，建议用 VS Code Live Server / 任意本地静态服务器打开。

交互：
- 第一屏：滚轮向下进入第二屏；顶部“自我介绍/合作流程”可直接跳转。
- 第二屏：第一次向下滚播放 About Me 内部转场；再次向下滚进入第三屏。向上反向操作。
- 第二屏进入第三屏：About Me 画面从中间分裂，左右两半向两侧退出，第三屏从中央逐步露出并铺满全屏；从第三屏返回时会反向合拢。
- 第三屏：滚轮控制原跑道动画；回退到起点后继续向上滚返回第二屏。
- 右侧细圆点可直接切屏。

所有原始资源均保留在 screens/screen1~3 内。
